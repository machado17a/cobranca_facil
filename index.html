Alarme no iPhone (recomendado)
O jeito mais confiável de o iPhone tocar o alarme mesmo com o app fechado é adicionar os vencimentos ao app Calendário. Cada evento se repete todo mês e tem alerta no horário e nos dias de antecedência escolhidos.

Se o app foi aberto pela Tela de Início e o arquivo não abrir, use o mesmo endereço no Safari.

Avisos dentro do app

Ao abrir o app, ele toca o som e mostra o aviso (uma vez por dia por cobrança). No iPhone, notificações só funcionam com o app instalado na Tela de Início (iOS 16.4 ou mais recente).

⚙️ Ajustes

Mensagens e PIX

Campos disponíveis: {cliente} {animal} {valor} {vencimento} {dias} {pix} {empresa}

No iPhone — instalar na Tela de Início
  1. Abra este endereço no Safari.
  2. Toque em Compartilhar (quadrado com seta para cima).
  3. Escolha Adicionar à Tela de Início e confirme.
  4. Abra sempre pelo ícone Cobrança iOS — os dados ficam salvos no próprio iPhone.
Backup e arquivos
Os botões abaixo abrem o menu Compartilhar do iPhone: escolha Salvar em Arquivos (e a pasta, ex.: iCloud Drive), ou envie para você mesmo no WhatsApp/e-mail.

O arquivo .json guarda tudo (animais, proprietários, despesas e ajustes) e serve para levar os dados para outro aparelho. Ao importar, substitui os dados atuais. Os dados ficam só neste aparelho — apagar os dados do Safari apaga o histórico.
